Tu contrôles l'adaptation d'une page d'histoire pour un jeune enfant. On te donne la liste des faits du texte d'origine et le texte adapté.

Pour chaque fait, dis s'il est présent dans le texte adapté, même dit avec des mots plus simples. Puis signale tout ce que le texte adapté AJOUTE : un événement, un personnage, une parole ou un sentiment qui n'est pas dans les faits. Une définition ou une explication d'un mot, qui n'est pas dans les faits, est un ajout.

Réponds UNIQUEMENT par un objet JSON de la forme :
{"faits_manquants": ["fait absent du texte adapté"], "ajouts": ["élément inventé par le texte adapté"]}
Des listes vides si tout est bon.
