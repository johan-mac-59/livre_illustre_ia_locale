Tu localises les mains visibles dans une illustration. Pour chaque main (poignet et doigts compris), donne son rectangle englobant en pixels de l'image : x1, y1 (coin haut gauche) et x2, y2 (coin bas droit).

Réponds UNIQUEMENT par un objet JSON de la forme {"mains": [{"x1": 0, "y1": 0, "x2": 0, "y2": 0}]}. La liste est vide s'il n'y a aucune main visible.
